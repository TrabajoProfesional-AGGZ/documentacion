\section{Manual (Aplicación socios) - Apartado de cuotas y pagos}

Para consultar el estado de cuenta y abonar las obligaciones correspondientes, el socio debe acceder a la sección de cuotas y pagos. En este apartado se puede visualizar el listado de todas las cuotas que se encuentran pendientes o vencidas.

\subsection{Proceso de pago y regularización}
Para que un socio logre regularizar su estado financiero, es requisito indispensable no tener ninguna cuota en estado vencido. El proceso para realizar el pago es el siguiente:

\begin{itemize}
    \item Se debe seleccionar la cuota a abonar (por ejemplo, la cuota de agosto de 2026).
    \item Al confirmar la intención de pago, el sistema redirigirá al usuario a la plataforma de Mercado Pago para procesar la transacción.
    \item Una vez que el pago se procesa de manera exitosa, la cuota pasará a figurar como pagada, manteniéndose en el listado únicamente aquellas que aún estén pendientes de vencimiento.
\end{itemize}

\subsection{Actualización del estado financiero}
Tras cancelar las deudas vencidas, el sistema actualiza automáticamente la situación del socio. Esto se refleja de dos maneras en la aplicación:
\begin{itemize}
    \item El estado general del usuario cambia inmediatamente a activo.
    \item En la sección superior de alertas aparecerá una notificación confirmando que se regularizó la situación financiera del socio.
\end{itemize}
