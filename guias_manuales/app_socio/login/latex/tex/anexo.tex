\section{Manual (Aplicación socios) - Login en la app, nociones básicas y generales}

Para acceder a la aplicación, el socio debe iniciar sesión ingresando el correo electrónico y la contraseña que configuró durante el proceso de registro de su cuenta.

\subsection{Pantalla principal}
Una vez que se ingresa correctamente, la pantalla principal mostrará la información básica del usuario:
\begin{itemize}
    \item Número de socio.
    \item Categoría a la que pertenece (por ejemplo, infantil, cadete o activo).
    \item Estado financiero actual (por ejemplo, al día o moroso).
\end{itemize}
Desde esta misma pantalla también se puede acceder al resto de las funcionalidades operativas de la aplicación.

\subsection{Perfil y cambio de contraseña}
Al ingresar a la sección de perfil, el usuario podrá visualizar todos sus datos personales. Además, este apartado ofrece las siguientes opciones:
\begin{itemize}
    \item \textbf{Cerrar sesión:} Para salir de la cuenta en el dispositivo.
    \item \textbf{Cambiar la contraseña:} Para realizar el cambio, el sistema solicita ingresar primero la contraseña actual y luego la nueva clave, verificando que ambas coincidan. Es importante tener en cuenta que, una vez confirmado el cambio de contraseña, la sesión se cerrará automáticamente por motivos de seguridad.
\end{itemize}
