\section{Manual (Aplicación socios) - Procesos de registro de socio}

Para que un socio que ya forma parte del club pueda acceder a la aplicación, primero debe realizar el proceso de registro y vinculación de su cuenta.

\subsection{Pasos para la configuración de la cuenta}
Al iniciar la aplicación, el usuario debe dirigirse al botón de configurar mi cuenta y seguir estos pasos para completar el registro:

\begin{itemize}
    \item \textbf{Validación de identidad:} Ingresar el número de socio y el número de documento correspondientes al socio que se desea registrar.
    \item \textbf{Datos personales:} Completar los datos básicos del socio.
    \item \textbf{Datos de contacto:} Ingresar la información de contacto solicitada por el formulario.
    \item \textbf{Credenciales de acceso:} Por último, definir un correo electrónico (mail) y una contraseña. Estos serán los datos utilizados para iniciar sesión a partir de este momento.
\end{itemize}

Una vez completados todos los pasos, la cuenta del socio quedará configurada exitosamente y ya estará habilitado para ingresar a la aplicación.
