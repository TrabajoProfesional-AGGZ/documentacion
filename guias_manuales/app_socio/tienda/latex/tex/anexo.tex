\section{Manual (Aplicación socios) - Apartado de tienda}

Para adquirir artículos oficiales del club, el usuario debe dirigirse a la sección de tienda, donde podrá visualizar el catálogo con todos los productos disponibles.

\subsection{Proceso de selección y pago}
Una vez elegido el artículo que se desea adquirir (por ejemplo, una remera blanca), el sistema solicitará indicar la cantidad requerida y mostrará el precio total a abonar.

Para concretar la operación, se debe avanzar al proceso de pago, el cual funciona con la misma dinámica utilizada para abonar reservas, cuotas o entradas:
\begin{itemize}
    \item El sistema redirigirá al usuario a la pasarela de Mercado Pago.
    \item Se deberá elegir el medio de pago deseado.
    \item Una vez procesado y aprobado el pago, la transacción quedará confirmada.
\end{itemize}

\subsection{Historial de compras}
Tras finalizar el pago, el socio podrá regresar al apartado de la tienda y acceder a la sección de mis compras. Allí quedará registrada de forma automática la adquisición recién realizada, permitiendo llevar un control del historial de artículos comprados.
