\section{Manual (Aplicación socios) - Apartado de trámites}

Para gestionar solicitudes y presentar documentación de forma digital, el socio debe dirigirse a la sección de mis trámites. Al ingresar por primera vez, el listado aparecerá vacío si no hay gestiones previas.

\subsection{Carga de nuevos trámites}
Para iniciar una nueva solicitud (por ejemplo, la presentación de un apto médico), el usuario debe seguir estos pasos:
\begin{itemize}
    \item Seleccionar la opción para cargar un nuevo trámite.
    \item Indicar el tipo de trámite a realizar.
    \item Elegir y adjuntar el archivo o documento correspondiente desde el dispositivo.
    \item Enviar la solicitud.
\end{itemize}

\subsection{Seguimiento y estado de aprobación}
Una vez enviado el documento, el trámite quedará con el estado "en revisión". Durante esta etapa, un empleado del club se encargará de verificar que la documentación enviada esté en orden para proceder a su validación. 

Luego de un tiempo, cuando el personal del club haya realizado el control, el socio podrá volver a ingresar a la sección de mis trámites y verificar que el estado de su solicitud se ha actualizado a "aprobado".
