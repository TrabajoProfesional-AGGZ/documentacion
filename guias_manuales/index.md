# Guías y manuales de Uso

En esta sección se encuentra la documentación funcional, manuales en formato PDF y videotutoriales para las diferentes plataformas del sistema SocioUnido.

### Plataformas disponibles

* **[Plataforma web (Panel administrativo)](plataforma_web/):** Manuales y guías sobre la administración general, gestión de socios, disciplinas, reservas, métricas y configuración.
* **[Aplicación móvil PWA (Para socios)](app_socio/):** Instructivos para el usuario final sobre el registro, uso del carnet digital, pago de cuotas, reservas y acceso a novedades.
* **[Aplicación móvil PWA (Para empleados)](app_trabajadores/):** Documentación orientada al personal del club, incluyendo el control de accesos mediante el lector QR.
