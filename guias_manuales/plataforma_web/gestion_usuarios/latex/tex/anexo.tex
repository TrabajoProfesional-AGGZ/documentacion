\section{Manual (Plataforma web) - Apartado de gestión de usuarios administrativos}

Al ingresar a la página de usuarios administrativos, el sistema despliega un listado completo que incluye tanto a los usuarios activos como a los inactivos[cite: 26].

\subsection{Búsqueda y filtrado de cuentas}
De manera análoga a la gestión de socios, la plataforma ofrece herramientas para localizar cuentas específicas[cite: 26]:

\begin{itemize}
    \item \textbf{Filtros:} Se puede filtrar a los usuarios según sus roles (por ejemplo, administrador o recepcionista)[cite: 26].
    \item \textbf{Búsqueda directa:} Es posible buscar ingresando el nombre, el apellido o el correo electrónico (por ejemplo, buscando la cuenta de "deportes")[cite: 26].
\end{itemize}

\subsection{Detalle de usuario y cambio de rol}
Al ingresar al detalle de un usuario administrativo particular, se habilitan distintas opciones de gestión[cite: 26]:

\begin{itemize}
    \item Visualizar los permisos que tiene asignados[cite: 26].
    \item Editar sus datos personales, como el nombre y el apellido[cite: 26].
    \item Realizar un cambio de rol[cite: 26]. Cabe destacar que esta acción es exclusiva y solamente la pueden ejecutar aquellos usuarios que posean el rol de administrador o superadministrador[cite: 26].
\end{itemize}

\subsection{Creación de nuevos usuarios}
Desde este mismo apartado se puede dar de alta a un nuevo usuario administrativo[cite: 26]. El formulario de creación es muy similar al de los socios y requiere ingresar los siguientes datos[cite: 26]:

\begin{itemize}
    \item Nombre y apellido (por ejemplo, María González)[cite: 26].
    \item Fecha de nacimiento y documento[cite: 26].
    \item Correo electrónico (mail) y una contraseña[cite: 26].
    \item Rol asignado a la cuenta (por ejemplo, tesorero)[cite: 26].
\end{itemize}

Una vez confirmada la creación, el nuevo usuario aparecerá en el listado general con su rol correspondiente[cite: 26]. Si posteriormente se desea modificar su acceso (por ejemplo, cambiándolo de tesorero a encargado de prensa), el rol quedará actualizado de forma correcta e inmediata[cite: 26].
