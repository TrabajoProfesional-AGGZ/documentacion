\section{Manual (Plataforma web) - Apartado de gestión de usuarios administrativos}

Al ingresar a la página de usuarios administrativos, el sistema despliega un listado completo que incluye tanto a los usuarios activos como a los inactivos.

\subsection{Búsqueda y filtrado de cuentas}
De manera análoga a la gestión de socios, la plataforma ofrece herramientas para localizar cuentas específicas:

\begin{itemize}
    \item \textbf{Filtros:} Se puede filtrar a los usuarios según sus roles (por ejemplo, administrador o recepcionista).
    \item \textbf{Búsqueda directa:} Es posible buscar ingresando el nombre, el apellido o el correo electrónico (por ejemplo, buscando la cuenta de "deportes").
\end{itemize}

\subsection{Detalle de usuario y cambio de rol}
Al ingresar al detalle de un usuario administrativo particular, se habilitan distintas opciones de gestión:

\begin{itemize}
    \item Visualizar los permisos que tiene asignados.
    \item Editar sus datos personales, como el nombre y el apellido.
    \item Realizar un cambio de rol. Cabe destacar que esta acción es exclusiva y solamente la pueden ejecutar aquellos usuarios que posean el rol de administrador o superadministrador.
\end{itemize}

\subsection{Creación de nuevos usuarios}
Desde este mismo apartado se puede dar de alta a un nuevo usuario administrativo. El formulario de creación es muy similar al de los socios y requiere ingresar los siguientes datos:

\begin{itemize}
    \item Nombre y apellido (por ejemplo, María González).
    \item Fecha de nacimiento y documento.
    \item Correo electrónico (mail) y una contraseña.
    \item Rol asignado a la cuenta (por ejemplo, tesorero).
\end{itemize}

Una vez confirmada la creación, el nuevo usuario aparecerá en el listado general con su rol correspondiente. Si posteriormente se desea modificar su acceso (por ejemplo, cambiándolo de tesorero a encargado de prensa), el rol quedará actualizado de forma correcta e inmediata.
