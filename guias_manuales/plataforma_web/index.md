# Plataforma web (Panel administrativo)

Seleccioná un apartado para visualizar la guía correspondiente:

* **[Login en la web, nociones básicas y generales](login/):** Acceso al panel y conceptos básicos de uso.
* **[Home (Explorando funcionalidades, vistas y atajos)](home/):** Recorrido por el tablero de control principal y accesos rápidos.
* **[Apartado de gestión de socios](gestion_socios/):** Administración integral del padrón de socios.
* **[Apartado de gestión de usuarios administrativos](gestion_usuarios/):** Control de accesos y roles para el personal que opera el panel.
* **[Apartado de métricas](metricas/):** Visualización de estadísticas y reportes de la institución.
* **[Apartado de gestión de reservas e instalaciones](gestion_reservas/):** Administración de los espacios físicos y los turnos.
* **[Apartado de gestión de disciplinas](gestion_disciplinas/):** Configuración de deportes, horarios y profesores.
* **[Apartado de noticias](noticias/):** Creación y publicación de novedades para los socios.
* **[Apartado de alertas](alertas/):** Configuración de notificaciones importantes.
* **[Apartado de tienda](tienda/):** Gestión de artículos, ventas y stock.
* **[Apartado de eventos](eventos/):** Organización y difusión de eventos especiales.
