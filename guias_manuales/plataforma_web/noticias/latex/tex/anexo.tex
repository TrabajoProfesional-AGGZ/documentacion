\section{Manual (Plataforma web) - Apartado de noticias}

Al ingresar a la sección de noticias, el usuario (como puede ser un integrante de prensa del club) podrá visualizar el listado completo de las noticias publicadas[cite: 13].

\subsection{Detalle de noticias publicadas}
Al entrar al detalle de una novedad en particular, la plataforma exhibe la siguiente información[cite: 13]:
\begin{itemize}
    \item Título[cite: 13].
    \item Foto[cite: 13].
    \item Fecha de publicación[cite: 13].
    \item Fecha de vencimiento[cite: 13].
    \item Desarrollo o cuerpo de la noticia[cite: 13].
\end{itemize}

\subsection{Creación de noticias}
Además de la visualización, el sistema permite publicar una nueva noticia[cite: 13]. Durante el proceso de creación, se deben completar los datos fundamentales, como el título (por ejemplo, "noticia prueba"), la descripción o cuerpo de la novedad, y la fecha de vencimiento[cite: 13]. Una vez creada, la noticia queda disponible para su visualización con todos los detalles cargados[cite: 13].
