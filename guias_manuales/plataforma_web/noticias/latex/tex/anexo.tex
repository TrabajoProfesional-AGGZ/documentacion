\section{Manual (Plataforma web) - Apartado de noticias}

Al ingresar a la sección de noticias, el usuario (como puede ser un integrante de prensa del club) podrá visualizar el listado completo de las noticias publicadas.

\subsection{Detalle de noticias publicadas}
Al entrar al detalle de una novedad en particular, la plataforma exhibe la siguiente información:
\begin{itemize}
    \item Título.
    \item Foto.
    \item Fecha de publicación.
    \item Fecha de vencimiento.
    \item Desarrollo o cuerpo de la noticia.
\end{itemize}

\subsection{Creación de noticias}
Además de la visualización, el sistema permite publicar una nueva noticia. Durante el proceso de creación, se deben completar los datos fundamentales, como el título (por ejemplo, "noticia prueba"), la descripción o cuerpo de la novedad, y la fecha de vencimiento. Una vez creada, la noticia queda disponible para su visualización con todos los detalles cargados.
