\section{Manual (Plataforma web) - Apartado de tienda}

Al ingresar a la tienda de productos, se puede visualizar un listado con todos los artículos disponibles, donde cada uno muestra su precio, el stock actual y una pequeña foto.

\subsection{Detalle de producto y compras}
Al acceder a un producto en particular, la plataforma permite ver su foto en detalle y la cantidad de stock disponible. Desde esta pantalla es posible registrar una compra directa para un socio.

Pasos para registrar la compra:
\begin{itemize}
    \item Ingresar el número del socio correspondiente (por ejemplo, socio número 1000).
    \item Al confirmar la operación, el sistema descuenta automáticamente las unidades del stock y la compra queda realizada correctamente.
\end{itemize}

\subsection{Edición de artículos}
En caso de ser necesario, el sistema permite modificar los datos de los artículos ya cargados. Al editar un producto, se pueden actualizar los siguientes valores:

\begin{itemize}
    \item \textbf{Foto:} Cambiar la imagen del artículo.
    \item \textbf{Precio:} Actualizar el valor de venta del producto.
    \item \textbf{Stock:} Ajustar las unidades disponibles (por ejemplo, si se realizó una reposición y el inventario vuelve a 100).
\end{itemize}

Al guardar los cambios, el producto quedará correctamente actualizado en el listado general de la tienda.
