\section{Manual (Plataforma web) - Apartado de tienda}

Al ingresar a la tienda de productos, se puede visualizar un listado con todos los artículos disponibles, donde cada uno muestra su precio, el stock actual y una pequeña foto[cite: 24].

\subsection{Detalle de producto y compras}
Al acceder a un producto en particular, la plataforma permite ver su foto en detalle y la cantidad de stock disponible[cite: 24]. Desde esta pantalla es posible registrar una compra directa para un socio[cite: 24].

Pasos para registrar la compra[cite: 24]:
\begin{itemize}
    \item Ingresar el número del socio correspondiente (por ejemplo, socio número 1000)[cite: 24].
    \item Al confirmar la operación, el sistema descuenta automáticamente las unidades del stock y la compra queda realizada correctamente[cite: 24].
\end{itemize}

\subsection{Edición de artículos}
En caso de ser necesario, el sistema permite modificar los datos de los artículos ya cargados[cite: 24]. Al editar un producto, se pueden actualizar los siguientes valores[cite: 24]:

\begin{itemize}
    \item \textbf{Foto:} Cambiar la imagen del artículo[cite: 24].
    \item \textbf{Precio:} Actualizar el valor de venta del producto[cite: 24].
    \item \textbf{Stock:} Ajustar las unidades disponibles (por ejemplo, si se realizó una reposición y el inventario vuelve a 100)[cite: 24].
\end{itemize}

Al guardar los cambios, el producto quedará correctamente actualizado en el listado general de la tienda[cite: 24].
